# בית להתהוות
מרחב לחלימה, דיאלוג ובקשת דרך.

## הפעלה במחשב
```
npm install
npm run dev
```
ואז לפתוח את http://localhost:5173

כל עוד `src/firebase-config.js` ריק, האתר רץ ב**מצב הדגמה**: הכל נשמר רק בדפדפן, ואת.ה אוטומטית מנהל.ת.

## מבנה
| קובץ / תיקייה | מה יש שם |
|---|---|
| `src/content/defaults.js` | תוכן הפתיחה: טקסט העיתוי, "מהו חדש", המצפן, מרחבי החיים, הקלפים, הספרייה, הרשומה הראשונה ביומן |
| `src/pages/` | המסכים: שער הכניסה, העיתוי, החלום הרחב (וגן החלומות), החלום שלי, מרחבי חיים, מעמיקים ומשתנים, דגדוג חלומות, מהתפר, מהו חדש, ניהול |
| `src/components/Botanical.jsx` | האיורים הבוטניים, ראש המרחב ושכבת "להעמיק" |
| `src/content/previous.js` | נוסחים קודמים – כדי ש"עדכון לנוסח החדש" ידע מה לא נערך ידנית |
| `firestore.rules` | כללי האבטחה: קריאה פתוחה, כתיבה אחרי הרשמה, עריכת תוכן רק למארחים |
| `public/audio/` | קבצי מוזיקה ומדיטציה |
| `public/harvest-reminders.ics` | תזכורות לקציר העונתי, לייבוא ליומן |

## אחרי ההעלאה הראשונה לאוויר
1. להיכנס לאתר עם החשבון שלך.
2. ללכת ל־`/admin` וללחוץ **"אני המארח הראשי"** (פעם אחת בלבד – מי שלוחץ ראשון הופך למארח).
3. בלשונית **התחלה** – ללחוץ **"טעינת תוכן הפתיחה"**.
4. מכאן הכל נערך מתוך ממשק הניהול: טקסטים, מצפן, מרחבי חיים, קלפים, ספרייה, הרשאות, מוזיקה.

## העלאת עדכונים
```
npm run deploy
```

## מה מחכה לשלב השני
מפת מרחבים אינטראקטיבית, הדמיות AI, לוח מפגשים, תזכורות במייל.
